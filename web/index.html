You need your own ROM

This page runs T2: The Arcade Game (Sega Genesis, 1992) in your browser, with the mouse as the Menacer light gun. It contains no game data: it runs on the ROM of the original cartridge, which you have to provide yourself (a dump of a cartridge you own, the JUE release, sha1 ; a raw .md/.bin or an interleaved .smd file).

The file stays in this browser: it is checked and kept in the page's IndexedDB so that later visits start straight away. It is never uploaded anywhere.
