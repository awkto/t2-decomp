# Level-flow route for NextLevel / LevelEnd / the per-level loaders (port/game/levelflow.c).
# The lockstep states rarely cross a level end, so this route ends levels on purpose and runs on

#   python3 -I port/tools/scriptgate.py port/scripts/levelflow_gate.txt --hle all
